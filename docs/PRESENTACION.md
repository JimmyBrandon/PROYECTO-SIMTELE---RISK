# Recorrido sugerido para la presentación

1. Mostrar el panel general y las cuatro tarjetas.
2. Abrir cada caso y señalar la pregunta, métodos y escenarios disponibles.
3. Ejecutar una condición y explicar que las entradas son sintéticas.
4. Leer la tabla comparativa y abrir el detalle de iteraciones/pasos.
5. Interpretar las dos gráficas y separar conclusión numérica de conclusión del caso.
6. Abrir Historial, recuperar la corrida y repetirla.
7. Mostrar `/health` solo si se solicita evidencia del servidor.

Esta versión implementa el flujo interactivo del simulador. Los datos deben contrastarse con los desarrollos analíticos del equipo antes de usarlos como resultados definitivos del informe.
